# Frontend accessibility

- **A11Y-1** — Every image has alt text that says what it shows; decorative images use an empty `alt`.
- **A11Y-2** — Every button and link has an accessible name: visible text, or an `aria-label` for icon-only controls.
- **A11Y-3** — State is never conveyed by colour alone; pair colour with text or an icon that has a label.
